# SocialSphere

Учебный веб-проект в рамках лабораторной работы №2  
«Настройка рабочего окружения для веб-разработки».

## Описание проекта
**SocialSphere** — прототип социальной сети с базовым пользовательским интерфейсом.
Проект создан с целью освоения настройки рабочего окружения, работы с системой контроля версий Git, 
инструментами веб-разработки и проектирования интерфейсов.

В рамках проекта реализована главная страница с лентой публикаций, формой добавления постов и простым
пользовательским профилем.

## Используемые технологии
- HTML5 — структура страницы
- CSS3 — стилизация интерфейса
- JavaScript — базовая интерактивность
- Node.js и npm — настройка окружения и управление зависимостями
- Git — система контроля версий
- GitHub — удалённый репозиторий
- Visual Studio Code — среда разработки
- Figma — проектирование интерфейса
